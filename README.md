# Yves Abdallah — Data & Analytics Projects

Projects and code samples in Python, Power BI, SQL, and R, developed alongside my studies in Big Data, Artificial Intelligence, and Management at Centrale Nantes and Audencia.

| Project | Tools | Contents |
| --- | --- | --- |
| [Country development clustering](python/country-clustering/) | Python, pandas, scikit-learn | World Bank data, preprocessing, K-means, hierarchical clustering, and PCA visualization |
| [PCA and digit recognition](python/pca-and-digit-recognition/) | Python, scikit-learn | Comparison of a k-NN classifier before and after dimensionality reduction |
| [Debt dashboard](power-bi/) | Power BI | Report file and a labelled layout preview |
| [Library database](sql/) | SQL / PostgreSQL | Relational schema with primary and foreign keys |
| [Air-quality filtering](r/) | R | CSV filtering and a reproducible simulation sample |
| [Cancer classification](python/cancer-classification/) | Python, scikit-learn | Saved analysis and feature-selection results; source CSV still needed for rerunning |

Each folder includes a short explanation, the project file, and available previews. The SQL and R files currently included are small code samples; larger projects can be added later.

## Run the Python projects

Use Python 3.12 and install the packages in [python/requirements.txt](python/requirements.txt), then open the notebooks in Jupyter or Google Colab. Country clustering requires internet access to the World Bank API. The digit-recognition dataset is included with scikit-learn. Individual READMEs explain any missing inputs or validation limits.
