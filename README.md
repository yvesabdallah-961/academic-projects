# Yves Abdallah — Data Portfolio

Python, R, and SQL projects from my studies in Big Data, Artificial Intelligence, and Management at Centrale Nantes and Audencia.

## Projects

### 1. Financial News Sentiment Classification

**Advanced NLP project.** Classifies 5,842 financial-news sentences using TF-IDF models, a Bi-LSTM, and FinBERT. Compares models with weighted F1 scores and explains class imbalance.

[Open the project](python/financial-sentiment-analysis/)

### 2. Machine Learning Model Comparison

**Advanced machine-learning lab.** Compares linear and logistic regression, Ridge, Lasso, Random Forest, and XGBoost with cross-validation, ROC/AUC, threshold tuning, and hyperparameter search.

[Open the project](python/machine-learning-model-comparison/)

### 3. Country Development Clustering

**Real-data clustering project.** Groups 211 countries using eight World Bank indicators and compares K-means with hierarchical clustering.

![Countries grouped using eight development indicators](python/country-clustering/country-clusters.png)

[Open the project](python/country-clustering/)

### 4. PCA and Handwritten Digit Recognition

**Dimensionality-reduction project.** Reduces 64 features to 31 while test accuracy changes from 96.44% to 96.22% on one fixed split.

![Accuracy and feature-count comparison](python/pca-and-digit-recognition/digits-pca-comparison.png)

[Open the project](python/pca-and-digit-recognition/)

### 5. Air Pollution Data Cleaning in R

**R data-quality project.** Cleans and summarizes 18,980 air-monitoring records from seven Chinese cities, including missing-data checks and PM2.5 analysis.

[Open the project](r/pollution-analysis/)

### 6. Colon Cancer Classification

**Educational classification project.** Uses logistic regression, standardized preprocessing, ROC/AUC evaluation, coefficient interpretation, and feature selection on gene-expression data.

![Colon cancer model comparison](python/colon-cancer-classification/model-comparison.png)

[Open the project](python/colon-cancer-classification/)

### 7. Library Database Schema

**SQL database-design sample.** Defines ten related tables for books, copies, members, authors, keywords, and borrowings using primary and foreign keys.

![Library schema and table relationships](sql/library-schema-preview.png)

[Open the SQL schema](sql/)
