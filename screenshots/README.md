# Portfolio Visuals

These are the main visual results from the portfolio. Each image has a simple title and a short explanation so a recruiter can understand it without opening the notebook first.

## Country development clustering

- [Country groups](../python/country-clustering/country-clusters.png) — countries grouped by development indicators; similar colors represent similar profiles.
- [Health and wealth view](../python/country-clustering/country-wealth-health.png) — a readable comparison of health and income patterns across countries.
- [Choosing the number of groups](../python/country-clustering/cluster-count-comparison.png) — compares candidate cluster counts before selecting a practical grouping.
- [Hierarchical clustering tree](../python/country-clustering/hierarchical-tree.png) — shows how countries merge into larger groups in the hierarchical method.

## PCA and handwritten digits

- [PCA accuracy trade-off](../python/pca-and-digit-recognition/digits-pca-comparison.png) — shows how reducing 64 pixel features to 31 changes test accuracy.
- [Digit examples](../python/pca-and-digit-recognition/digit-examples.png) — sample handwritten digits used by the classifier.
- [PCA variance explained](../python/pca-and-digit-recognition/pca-variance.png) — shows how many components are needed to preserve information.
- [Digit reconstruction](../python/pca-and-digit-recognition/digit-reconstruction.png) — compares original digits with their lower-dimensional reconstructions.
- [Digit confusion matrix](../python/pca-and-digit-recognition/digit-confusion-matrix.png) — shows which digit classes are easiest or hardest to distinguish.

## Colon cancer classification

- [Model comparison](../python/colon-cancer-classification/model-comparison.png) — compares the full logistic model with reduced feature sets.
- [ROC curve](../python/colon-cancer-classification/roc-curve.png) — visualizes the classifier's ability to separate the two classes across thresholds.

## SQL database design
