# Portfolio Visuals

These are the main visual results from the portfolio. Each image has a simple title and a short explanation so a recruiter can understand it without opening the notebook first.

## Country development clustering

- [Country groups](country-development-groups.png) — countries grouped by development indicators; similar colors represent similar profiles.
- [Health and wealth view](health-and-wealth.png) — a readable comparison of health and income patterns across countries.
- [Choosing the number of groups](choose-number-of-groups.png) — compares candidate cluster counts before selecting a practical grouping.
- [Hierarchical clustering tree](hierarchical-clustering-tree.png) — shows how countries merge into larger groups in the hierarchical method.

## PCA and handwritten digits

- [PCA accuracy trade-off](pca-accuracy-tradeoff.png) — shows how reducing 64 pixel features to 31 changes test accuracy.
- [Digit examples](handwritten-digit-examples.png) — sample handwritten digits used by the classifier.
- [PCA variance explained](pca-variance-explained.png) — shows how many components are needed to preserve information.
- [Digit reconstruction](digit-reconstruction.png) — compares original digits with their lower-dimensional reconstructions.
- [Digit confusion matrix](digit-confusion-matrix.png) — shows which digit classes are easiest or hardest to distinguish.

## Colon cancer classification

- [Model comparison](colon-cancer-model-comparison.png) — compares the full logistic model with reduced feature sets.
- [ROC curve](colon-cancer-roc-curve.png) — visualizes the classifier's ability to separate the two classes across thresholds.

## SQL database design

- [Library database schema](library-database-schema.png) — maps the tables and their primary-key/foreign-key relationships.
